# Psychology Survey — User App

Клиентская часть системы психологического опроса. Пользователь может зарегистрироваться, подтвердить код, войти в систему и пройти опрос, загружаемый через REST API.

## Возможности

- регистрация пользователя;
- вход по учётным данным;
- отдельный экран подтверждения кода;
- сохранение access token в cookie;
- проверка авторизации перед открытием dashboard;
- загрузка структуры опроса и вариантов ответа из API;
- отправка выбранных ответов;
- уведомления об успешных и ошибочных операциях;
- адаптивный интерфейс.

## Технологии

- React 18
- TypeScript
- React Router
- Ant Design
- Zustand
- Axios
- SCSS
- Vite
- Docker

## Запуск локально

```bash
git clone https://github.com/Azamov-Otabek/psixolog-user.git
cd psixolog-user
npm install
npm run dev
```

Приложение использует API `https://api.nordik-tadqiqot.uz`. Для полного пользовательского сценария API должен быть доступен.

## Production-сборка

```bash
npm run build
npm run preview
```
